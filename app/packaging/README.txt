WEXdesktop — двухпанельный файловый менеджер с инструментами для APK.

Запуск:
    ./start.sh
(или bin/WEXdesktop — но под Wayland лучше через start.sh)

Ставить ничего не нужно: Java лежит внутри папки. Папку можно положить куда угодно,
например в ~/Apps/WEXdesktop, и запускать оттуда.

Программа работает одним процессом: открытие файла из другой программы не запускает
вторую копию, а показывает окно уже работающей. Полный выход — Ctrl+Q.

Чтобы окна открывались сразу, процесс можно поднимать при входе в систему:
    ./start.sh --background
Окна при этом не появляются — программа просто ждёт. Добавьте эту строку в автозапуск
своей оболочки (или положите .desktop-файл в ~/.config/autostart).

Настройки хранятся в ~/.config/wexdesktop, кэш — в ~/.cache/wexdesktop.
Удалить программу — просто удалить папку (и эти два каталога, если не жалко настроек).

Необязательные программы, которые расширяют возможности, если они есть в системе:
    fd, ripgrep      — быстрый поиск по именам и по содержимому
    ffmpeg           — миниатюры и просмотр видео
    poppler          — страницы PDF (pdfinfo, pdfunite)
    7zip, unrar      — архивы .7z и .rar
    adb              — установка APK на телефон
    git              — пометки изменённых файлов в репозитории
    ssh              — панель с папками на сервере
