WEX Desktop

Двухпанельный файловый менеджер с редактором, терминалом и инструментами для APK.

Запуск в Linux:
    ./start.sh
    ./start.sh --help
    ./start.sh --version

Java включена в дистрибутив. Распакованную папку можно разместить, например,
в ~/Apps/WEXdesktop. Скрипт start.sh задаёт окружение для запуска под Wayland.

Повторный запуск передаёт файл уже работающему экземпляру. Полный выход — Ctrl+Q.
Для запуска без окна при входе в систему добавьте в автозапуск оболочки:
    /path/to/WEXdesktop/start.sh --background

Настройки: ~/.config/wexdesktop/
Кэш:       ~/.cache/wexdesktop/

Внешние инструменты для отдельных функций:
    fd, rg                  поиск файлов и текста
    git                     состояние файлов в репозитории
    ssh, sftp               файлы на сервере
    adb                     файлы и приложения Android-устройства
    7z, unrar               архивы 7z и RAR
    ffmpeg, ffprobe, ffplay  аудио, видео и миниатюры
    Poppler                 просмотр, извлечение текста и объединение PDF
    Chromium / Chrome       предпросмотр HTML
    objdump / llvm-objdump   дизассемблирование ELF

Удаление: закройте WEX и удалите папку приложения. Настройки и кэш удаляются отдельно.
