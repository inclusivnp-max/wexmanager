# WEX Desktop 1.0.0

Первый выпуск с готовыми сборками для Linux x64, Windows x64 и Android.

## Основное

- Две файловые панели, вкладки, закладки, поиск по имени и содержимому,
  копирование, перенос, корзина и отмена файловых операций.
- Редактор с подсветкой, поиском и заменой, несколькими каретками, сворачиванием
  блоков и предпросмотром Markdown и HTML.
- PDF-читалка с темами, миниатюрами, закладками, поиском и сохранением места чтения.
- Работа с APK, DEX, Smali, ресурсами Android и Java-классами.
  Декомпиляторы: jadx, CFR, Vineflower и Procyon.
- Терминал, архивы как папки, SSH/SFTP и подключение Android-устройств по ADB.

## Последние изменения

- Вложенные и сгенерированные части DEX/Java-класса собраны в группу.
  Можно открыть весь класс в Java или выбрать отдельную часть для Smali.
- Окна текстовых редакторов не блокируют менеджер и друг друга.
- «Показать в менеджере» выбирает файл, прокручивает к нему список и
  использует уже открытую вкладку. Повторное нажатие не перечитывает папку в потоке окна.
- Исправлены перенос слов, обработка нескольких файлов из внешних программ
  и отображение длинных описаний подсказок.
- В README добавлены скриншоты основных инструментов.

## Установка

- **Linux:** распакуйте `WEXdesktop-linux-x64.tar.gz` и запустите `WEXdesktop/start.sh`.
- **Windows:** откройте `WEXdesktop-1.0.0.msi` и пройдите установку.
- **Android:** установите `WEX-Android-1.0.0-debug.apk` на Android 8.0 или новее.

В настольных пакетах уже есть Java. Для PDF нужен Poppler; для отдельных
возможностей — внешние программы из таблицы в [README](../../README.md#внешние-инструменты).
Android APK подписан отладочным ключом; при смене ключа в следующем выпуске
понадобится удалить предыдущий APK.

Контрольные суммы установочных файлов опубликованы в `SHA256SUMS` рядом со сборками.
