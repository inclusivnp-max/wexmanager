# Интерфейс WEX

Возвращена исходная схема интерфейса — до изменений тулбара.

```text
WEX Desktop · MT Manager Edition · подсказки клавиш    История · Настройки · Обмен
┌─────────────────────────────────┬─────────────────────────────────┐
│ ← → ↑ [путь] ⧉ ✎ [поиск] ▱ + ⚙ >_ ↻ │ ← → ↑ [путь] ⧉ ✎ [поиск] ▱ + ⚙ >_ ↻ │
│ Вкладки и избранные места        │ Вкладки и избранные места        │
│ Имя ↑            Размер  Дата    │ Имя ↑            Размер  Дата    │
│ Файлы                           │ Файлы                           │
│                                 │                                 │
│ [Все] [Инверсия] [По типу] [Снять]│                                 │
│ Статус папки и свободное место   │ Статус папки и свободное место   │
└─────────────────────────────────┴─────────────────────────────────┘
                   Открыть ту же папку в соседней панели
```

- Общей полосы «Создать / Копировать / Переместить / …» нет.
- Кнопки истории, настроек и обмена панелей находятся в исходной шапке.
  Отдельной кнопки «Меню» нет; подсказка клавиш открывает справку.
- В каждой панели сохранён оригинальный набор кнопок. «+» открывает выбор
  «Папку… / Файл…». Поиск раскрывается рядом с адресом, а не отдельной строкой.
- Панель выделения снова содержит «Все», «Инверсия», «По типу», «Снять».
- Переход в ту же папку соседней панели доступен на язычке между панелями.
- Возвращены исходные меню вида, строка состояния и поведение активации панелей.
- Читалка PDF, сохранение позиции чтения и остальные функции не менялись.

## Реализация

`DualPaneScreen.kt`, `FilePaneView.kt`, `FileItemRow.kt` и `ViewOptionsMenu.kt`
восстановлены побайтно из состояния до переработки интерфейса. Экспериментальные
`ManagerChrome.kt` и `ManagerFileToolbar.kt` удалены вместе с их тестами.
